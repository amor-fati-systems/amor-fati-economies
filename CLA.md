[CLA Assistant](https://cla-assistant.io/amor-fati-systems/amor-fati-economies).
The required `license/cla` check records that acceptance for the submitting
GitHub account.

Changes to the agreement must update its canonical source and hosted signing
copy together, then verify every repository linked to that signing copy.
